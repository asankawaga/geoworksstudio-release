# GeoWorksStudio

Professional AutoCAD **Civil 3D** plugin for geospatial / civil engineering workflows — grid &
TIN surfaces, volume calculations, PVD/settlement analysis, 3D solids, geometry tools, and point
group export. By **Hyperdim Innovation**.

This repository distributes the installer. The source code is maintained privately.

## Download

Get the latest installer from the [**Releases**](../../releases) page.

- Current beta: **1.0.0-beta.7**

## Requirements

- Windows x64
- AutoCAD **Civil 3D 2024, 2025, 2026, or 2027**
- Administrator rights to install

## Install

1. Download and run `GeoWorksStudio_Setup_<version>.exe`.
2. This beta is unsigned — if Windows SmartScreen warns, choose **More info → Run anyway**.
3. Restart AutoCAD Civil 3D and run the command **`GWS_MAIN`** to open the tool hub.

## Activation (licensed beta)

1. Run **`GWS_MAIN`** → **Activation**.
2. Click **Copy** to copy your machine fingerprint, and send it to your GeoWorksStudio contact.
3. You will receive a license file (`.lic`).
4. In **Activation**, click **Install License File…** and select it. All tools unlock.

Beta licenses are locked to your machine and valid for a limited period.
